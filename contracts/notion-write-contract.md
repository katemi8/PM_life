# Notion Write Contract

Notion is the source of truth for product documentation.

Rules:

- read relevant docs before drafting;
- do not update official docs without preview and explicit approval for the concrete change;
- when updating an existing document, show preview as a diff with old and new content before approval;
- verify writes by rereading the page after update;
- after readback, report whether the written result matches the approved preview/diff;
- keep raw KTalk transcript text out of official docs unless explicitly requested and approved.

If no approved Notion write-capable tool is available in the current agent environment, stop after preview/diff and report that the write cannot be performed in this session.

Preview alone is not enough.
