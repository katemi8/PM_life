# Approval Policy

Official Notion documentation may be changed only after explicit user approval for the concrete change.

Before a write, the agent must show:

- target;
- exact change;
- diff with old and new content when updating an existing document;
- source context;
- assumptions;
- risks;
- expected readback verification.

KTalk-derived meeting context may be used as source material for a preview or diff, but it must not be written to official Notion documentation without the same explicit approval and readback flow.

## Standard

For official Notion documentation:

```text
preview or diff + explicit approval for the concrete change + write + readback verification
```

Preview alone is not approval.

Generic approval such as "continue" or "do what is needed" is not enough for official documentation writes.
